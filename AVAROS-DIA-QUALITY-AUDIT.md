## Acceptance record

- Supported deterministic parser corpus: 266+ natural, paraphrased, typo, ambiguous, multi-entity, and follow-up cases passed.
- Live numerical cross-check: AVAROS matched the independently fetched Reneryo raw-series average within numeric tolerance.
- Live browser/HiveMind checks covered correct KPI, total-energy semantics, comparison, rank, average, trend, definition, target, diagnosis, recommendation, status, help, unavailable analytics, supplier scope, controls, invalid scenarios, unknown assets, future periods, no data, gibberish, and multi-turn context.
- Composite live latency: five browser-path factory-summary paraphrases returned nine complete core KPI rows with nearest-rank p95 `4.151 s`. Individual live KPI and comparison probes remained below 3 s.
- Isolated E2E stack: 39 messagebus, voice, and HiveMind/browser-path tests passed.
- Backend/unit/integration/Web UI API suite: 1,850 passed, 6 skipped, 1 expected failure.
- Frontend: 34 test files / 262 tests, TypeScript check, and production build passed.
- PREVENTION remained disabled for Reneryo acceptance, so AVAROS correctly did not advertise or simulate anomaly, drift, forecast, or proactive-alert results.
- Reneryo application behavior and data were not modified.
