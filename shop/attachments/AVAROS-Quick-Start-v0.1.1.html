AVAROS Quick Start

OVOS Assistant for Sustainable Manufacturing · Version 0.1.1

1. Requirements

  • Linux server or workstation
  • Docker Engine 26+ and Docker Compose v2
  • 4 GB RAM minimum and 10 GB free disk space
  • One available host port for the Web UI

2. Install

unzip avaros-dia-v0.1.1.zip
cd avaros-dia-v0.1.1
bash scripts/prepare-env.sh
docker compose up -d --build
docker compose ps

Open http://localhost:8080 and enter the AVAROS_WEB_API_KEY stored in the private .env file.

If port 8080 is occupied

Edit .env before starting:

AVAROS_WEB_PORT=9090
HIVEMIND_WS_URL=auto

Then open http://localhost:9090. Voice automatically follows the selected Web UI port.

Do not set the browser HiveMind URL to a Docker service name. Keep HIVEMIND_WS_URL=auto for local, LAN, and proxied deployments.

3. Try the demo platform

docker compose --profile demo up -d
Wizard fieldValue
Profile namedemo
API URLhttp://demo-platform:8090
AuthenticationBearer token
TokenAny non-empty test value

4. Configure your platform

The guided wizard covers:

  1. Platform endpoint and authentication
  2. Connection testing
  3. Asset registration and aliases
  4. Platform resource linking
  5. Metric mapping and validation
  6. Voice-intent activation
  7. Optional PREVENTION analytics

Use a platform URL reachable from inside Docker. A service running in another container must not be configured as localhost.

5. Verify and troubleshoot

curl http://localhost:8080/health
docker compose ps
docker compose logs --tail=200 avaros-web-ui hivemind avaros

Replace 8080 with your configured AVAROS_WEB_PORT.

6. Completely reset the test installation

Remove AVAROS containers, networks, volumes, and locally built images:

bash scripts/uninstall.sh

On a disposable machine, also remove every image referenced by AVAROS and delete the extracted release directory:

bash scripts/uninstall.sh --all-images
cd ..
rm -rf avaros-dia-v0.1.1
--all-images may remove images shared with another Docker Compose project. Use it only on a dedicated test machine.
