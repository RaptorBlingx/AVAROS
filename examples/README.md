# AVAROS sample data

`sample-production-data.csv` is an anonymized getting-started dataset for the Production Data page.

1. Create assets named `Line-1` and `Line-2`.
2. Open **Production Data**.
3. Upload the CSV file.
4. Review the import summary before accepting the records.

For live KPI API demonstrations, start the deterministic demo platform:

```bash
docker compose --profile demo up -d
```
