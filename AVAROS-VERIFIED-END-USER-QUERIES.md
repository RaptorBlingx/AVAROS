# AVAROS Verified End-User Query Catalogue

Date tested: 2026-08-14 UTC  
Active profile: `reneryo`  
Transport tested: natural-language utterances sent through the live OVOS message bus, using the same downstream voice path used by HiveMind/browser voice  
Data window used: `last month`

This catalogue contains only queries that returned a clear, useful spoken answer during the live test. The queries were sent as an end user would phrase them; intent names and internal API calls were not used.

The configured assets were `Line-1`, `Line-2`, and `Line-3`. The full 19-metric KPI matrix was tested for all three assets. The 54 entries below are the KPI results with clear metric labels, plus verified comparison, trend, anomaly, scenario, status, help, greeting, and safe-control queries.

## How to test

Open the AVAROS web interface and use the text/voice input, or say the query through the browser voice path. When a time period is relevant, use a historical period such as `last month`; the current seeded data does not contain values for every current-day query.

Expected behavior is shown after each query. Numeric values may change when the underlying Reneryo data changes.
